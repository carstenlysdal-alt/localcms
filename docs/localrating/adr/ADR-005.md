# ADR-005 – Production Engine-grænse, jobs og cron

Dato: 2. oktober 2026. Status: **Foreslået** (afventer ejerens godkendelse, Fase 0-gate). Hører til `docs/localrating/README.md`.

## Kontekst
CMS'et har ingen jobkø. Feed-hentning og AI-trin kan overskride request-timeout på Railway (`numReplicas: 1`, `railway.json:12`). Eksisterende mønster: `/api/cron/frontpage-rank` + Railway cron-service. T7/T8 anbefaler Cloud Scheduler i aI-library til *dagsorden/politi*.

## Beslutning
1. **Production-grænsen (opdateret 3. oktober 2026, ADR-015):** LocalRating ejer **kilderegistret** (`SourceDefinition`) og kilde-laget `SourceItem` → `StoryCandidate` → rating → generering. aI-library kan fortsat levere `Signal` (dagsorden/politi/trafik/vejr) for kilder med `ingestOwner=ailibrary`; reglen er **én ingest-ejer pr. kilde** (tidligere: "én kilde, ét system") med envejs dedupe-regel og drift-vagt (`04-…` §4a).
2. **Jobkø:** tabellen `ProductionJob` (queued/running/done/failed/dead, `runAfter`, lease `lockedUntil`, `dedupeKey`), claim via guardet `updateMany` (uden `SKIP LOCKED`; virker på SQLite og Postgres), reaper for udløbne leases, backoff via `backoffDelay`.
3. **Cron:** `/api/cron/localrating?task=tick|housekeeping|reconcile` (bearer `CRON_SECRET`, mønster fra `frontpage-rank`), 2. Railway cron-service hvert 5. minut; begrænsede, idempotente batches (≤ 40 s/tick). Kilde-prioritet P0/P1/P2 → `pollIntervalMinutes` 5/30/360 med P0-kapacitetsreservation; P0-gulv er 5 min (registrets 1–5 min kræver push/worker, senere) og discovery kører ugentligt som job (`10-…` §11d, §11f).
4. **Lange AI-trin** (generering) kører som detached job i den langlivede Node-proces med lease-heartbeat; UI følger via NDJSON-events; cron/reaper genoptager efter nedbrud.
5. **Retention** i `housekeeping`.

## Konsekvenser
+ Ingen ny infrastruktur (ingen broker); tabel-baseret og testbar.
− Detached jobs mistes ved genstart og genoptages via lease/reaper (accepteret, R20).
− Ved flere replikaer skal claims være guardede (er designet så).

## Alternativer (fravalgt)
- BullMQ/Redis-kø (Redis findes valgfrit): ny afhængighed, Redis ikke obligatorisk; afvist.
- Separat worker-service: ekstra drift; senere mulighed.
- Cloud Scheduler/Firebase: Y/aI-librarys tilgang; passer ikke til CMS'et.
