# ADR-012 – Domain events via transaktionel outbox (ProductionJob)

Dato: 2. oktober 2026. Status: **Foreslået** (afventer ejerens godkendelse, Fase 0-gate). Hører til `docs/localrating/README.md`.

## Kontekst
Spec §25 kræver domain events. CMS har ingen event-/queue-infrastruktur; kernen må ikke ændres. Knowledge ADR-008 anbefaler transaktionel outbox med inbox-dedup og at-least-once.

## Beslutning
1. En event er en `ProductionJob` med `kind="event:<TYPE>"`, skrevet i **samme transaktion** som den kanoniske ændring; envelope (`eventId, eventType, schemaVersion, instansId, aggregateType/Id/Version, occurredAt, correlationId, data`) med kun id'er/skalarer.
2. **Emitteret af LocalRating:** `FEED_ITEM_INGESTED` (for en `SourceItem`), `SOURCE_CREATED`, `SOURCE_APPROVED`/`SOURCE_REJECTED`, `DISCOVERY_STARTED`/`DISCOVERY_COMPLETED`/`DISCOVERY_SOURCE_PROPOSED`/`DISCOVERY_SOURCE_DEAD`/`DISCOVERY_SOURCE_MOVED`/`DISCOVERY_ALIAS_PROPOSED` (3. oktober 2026, `04-…` §4), `STORY_CANDIDATE_CREATED`, `STORY_CANDIDATE_RATED`, `DRAFT_GENERATED`, `ARTICLE_CREATED` (egen kladde).
3. **Observeret (polling/reconciliation ≤ 15 min), ikke push:** `ARTICLE_PUBLISHED/UPDATED`, `COMPOSITION_PUBLISHED`, `TIP_RECEIVED` (kun tællinger) → `*_OBSERVED`. Uden for v1: `STORY_UPDATED`, `METRICS_AGGREGATED`, `RECOMMENDATION_REQUESTED`.
4. At-least-once; `dedupeKey = <TYPE>:<aggregateId>:<version>`; handlere idempotente; dead-letter + gen-afspilning.

## Konsekvenser
+ Ingen ny infrastruktur; events og jobs deler mekanik.
− Forsinkelse på observerede events; evt. senere hook i kernen kan gøre dem til push uden at ændre handlere.

## Alternativer (fravalgt)
- Ny broker/Kafka: overkill.
- Hook i `publishArticle`: kerneændring; udskudt (D17).
