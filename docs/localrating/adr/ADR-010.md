# ADR-010 – Simulator og udgivelsesplan (kun forslag)

Dato: 2. oktober 2026. Status: **Foreslået** (afventer ejerens godkendelse, Fase 0-gate). Hører til `docs/localrating/README.md`.

## Kontekst
Ejeren vil se hvordan flowet virker og hvordan AI prioriterer/planlægger før noget går live. Forsidekernen har rene funktioner med `now`, men `calculateSupportedContentQuota` bruger `Date.now()`, og layout/snapshot/metrics er ikke "as-of".

## Beslutning
1. **Sandbox med virtuelt ur** (07/09/12/15/18/22 + frit) oven på de **rene** funktioner `rankCandidates/composeFrontpage/enforceGuardrails/resolveFrontpage` (uændrede); egen kvoteberegning med ækvivalenstest; **ingen skrivning til live**.
2. **Input:** rigtige eller syntetiske artikler/hændelser/kampagner.
3. **AI-udgivelsesplan:** zod-valideret JSON; **hårde regler** (pins/locks, kvoteloft, mærkning, Krimi/Sundhed, AI-assisteret ikke i hero, kun godkendt indhold) kan ikke tilsidesættes; planen *udfører intet*.
4. **Forklaring** af placeringer (delscore-nedbrydning pr. tidspunkt, deterministisk).
5. **"Anvend som forslag"** skriver kun `FrontpageSnapshot(status="forslag")` (+ `EditorialPriority` + `PlanItem` `proposed`); godkendelse sker i den eksisterende forsideeditor. **Shadow-mode** sammenligner redaktørens faktiske forside med motorens valg. Politiksammenligning.
6. Chat-lignende dele følger `chat-module`; operatøren kan oprette scenarier/planer, men `approve_snapshot` er blokeret.

## Konsekvenser
+ Sikker forhåndsvisning; samme kode som produktion.
− Politik-parametre begrænset til det kernen tager som data; rank-vægte kræver kerneændring (D13); arver kernens hardcodes (README nr. 5).

## Alternativer (fravalgt)
- Kald `resolveFrontpageForRender` i sandbox: ikke "as-of"; afvist.
- AI sætter forsiden direkte: forbudt (AI foreslår, redaktør godkender).
