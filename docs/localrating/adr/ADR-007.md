# ADR-007 – AI-gateway, globale nøgler og DeepSeek/GDPR

Dato: 2. oktober 2026. Status: **Foreslået** (afventer ejerens godkendelse, Fase 0-gate). Hører til `docs/localrating/README.md`.

## Kontekst
Y har tre kopier af en DeepSeek→Gemini-wrapper med **stille** cross-provider-fallback, ingen måling, ingen loft og hardcodede fallback-nøgler. CMS har én Anthropic-klient (`lib/frontpage/ai-client.ts`) uden usage-læsning. Ejeren: kun globale AI-nøgler i Railway.

## Beslutning
1. **`lib/ai/`:** provider-agnostisk gateway (`anthropic` default, `gemini`, `deepseek` valgfri) med model pr. opgave (env), `AiUsage`-række pr. kald (også afvisninger), circuit breaker pr. provider (`getBreaker`), timeout/retry, JSON-reparation + zod, **kaster aldrig**. `lib/frontpage/*` og `/api/chat` ændres ikke.
2. **Nøgler kun som Railway-variabler** (`ANTHROPIC_API_KEY`, `GEMINI_API_KEY`, `DEEPSEEK_API_KEY`, `EXA_API_KEY`, `LOCALRATING_*`); **ingen nøgler i DB, ingen BYOK-UI**; `lib/env.ts` advarer (ikke startfejl); `scripts/check-secrets.ts` udvides (inkl. regel mod `process.env.X || 'literal'`).
3. **Forbrugsloft fail-closed** pr. instans og globalt (0 = AI spærret); 80 %-advarsel.
4. **Ingen stille cross-provider-fallback;** fallback kun via eksplicit `fallbackChain` pr. opgave.
5. **GDPR:** DeepSeek spærret som standard og kun for `piiPolicy="no_pii"` feedtekst; aldrig tips/politi/kladder; default Anthropic. Ejeren verificerer databehandleraftaler.
6. **Y's lækkede nøgler** omtales kun; ejeren roterer hos udbyderne; Y-repoet røres ikke.

## Konsekvenser
+ Ét sted for omkostning, fejl og politik; reproducerbart.
− Priser/model-id'er skal verificeres i Fase 1; ny gateway-kode.

## Alternativer (fravalgt)
- BYOK/nøgler i DB: ejeren fravalgte.
- Automatisk fallback til billigste udbyder: dataflytning i det skjulte; afvist.
